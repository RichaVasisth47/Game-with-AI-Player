# Tic-Tac-Toe Game vs Smart AI 🎮

A classic Tic-Tac-Toe desktop game built using Python and the Tkinter library, featuring a graphical user interface (GUI) and an intelligent AI opponent.

## Features ✨
* **Interactive GUI:** Built with Python's Tkinter for a smooth window-based gameplay experience instead of the terminal.
* **Smart AI Bot:** Features built-in logic to evaluate winning opportunities, block your winning moves, and prioritize strategic placements.
* **Custom Color Scheme:** Distinct visual distinction with brown text for player moves (`X`) and red text for AI moves (`O`).
* **Auto Reset & Score Alerts:** Pop-up notifications declare the winner or a draw, then automatically reset the board for the next round.

## How to Run 🚀

1. Ensure you have Python installed on your system.
2. Clone this repository or download the project files.
3. Open your terminal or PyCharm terminal and run the game script:
   ```bash
   python main.py
